# Privacy Policy

Last updated: August 3, 2026

Frontend Design Premium is an instruction-only agent plugin published by TryHand Co., Ltd. It does not operate a hosted service, create user accounts, transmit project files to TryHand, or independently collect, store, sell, or share personal data.

The plugin runs inside the host product selected by the user. Files, prompts, tool calls, model processing, telemetry, and retention remain governed by the host product, the user's configuration, and any third-party tools the user separately enables. The plugin does not bundle an MCP server or external connector.

The plugin may instruct the host agent to read or modify files in the project the user has placed in scope and to run local validation commands. Those actions remain subject to the host product's sandbox, permissions, and approval controls.

Privacy questions may be submitted through the repository's public issue tracker: https://github.com/TryHand-Co-Ltd/frontend-design-premium/issues
