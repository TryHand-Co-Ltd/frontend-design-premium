# Frontend Design Premium for Cursor

This self-contained Agent Plugin bundles `frontend-design-premium` with the
compatibility-tested `frontend-design` skill it composes with. No separate
upstream skill installation is required.

After the plugin is listed publicly, open **Customize** in Cursor, search for
**Frontend Design Premium**, select **Install**, and choose project or user
scope. Skills can be selected by the agent or invoked manually with
`/frontend-design-premium`.

For local testing, copy or symlink this directory to:

```text
~/.cursor/plugins/local/frontend-design-premium
```

Then restart Cursor or run **Developer: Reload Window**.
